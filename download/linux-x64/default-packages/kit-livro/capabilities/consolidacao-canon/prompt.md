[Capacidade: Consolidação de Canon] Após a conclusão de uma unidade de trabalho (capítulo aprovado), executar o protocolo de consolidação:

EXTRAÇÃO DE FATOS:
1. Ler o artefato aprovado na íntegra — como extrator, não como revisor.
2. Extrair TODOS os fatos concretos estabelecidos (eventos, decisões, revelações).
3. Identificar estado atualizado de cada personagem (localização, físico, conhecimento, relações).
4. Mapear segredos/pistas plantados (com método de plantio).
5. Registrar novos detalhes sensoriais (cheiros, sons, texturas, cores, temperaturas).
6. Identificar dívidas narrativas pagas e novas dívidas criadas.
7. Registrar regras do mundo mostradas ao leitor.
8. Identificar riscos de repetição para capítulos futuros.

ATUALIZAÇÃO DE DOCUMENTOS GLOBAIS:
Para cada decisão local, verificar se altera:
- Definições, princípios ou posições → atualizar documento de referência conceitual.
- Estilo, tom ou forma de explicar → atualizar documento de voz.
- Estrutura ou objetivos de capítulos futuros → atualizar sumário.
- Mapa de conceitos (introdução, movimentação, restrição) → atualizar conceitos.

Se nenhuma promoção for necessária, registrar explicitamente: "Avaliação de promoção: nenhuma alteração necessária nos arquivos globais."

PRINCÍPIO: Nunca deixar decisões importantes presas apenas em artefatos locais. A memória do projeto deve ser sempre atualizada para que qualquer capítulo futuro possa ser escrito sem contradição.
